# 💻 macOS Dotfiles & Auto Sync Setup

This repo manages:
- Homebrew packages
- Zsh config
- Git config
- Starship prompt config
- FD ignore config
- Ghostty terminal config
- Ripgrep ignore config
- SSH config
- macOS preferences
- Auto-sync to GitHub

## 🚀 Setup (New Machine)

```bash
git clone https://github.com/sasith-axtondigital/Atlas.git ~/dotfiles
cd ~/dotfiles
chmod +x install.sh
./install.sh
